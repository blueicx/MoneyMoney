# 大神持仓回放深化

继续已确认的 SEC 13F 真实数据和可操作研究计划，不增加平行业务状态或无关功能区。

## 范围

- 严格比较同机构 CIK、相邻标准季度、同 CUSIP/类别/Put-Call/明确 SH 或 PRN 单位。
- 缺少单位、股数、机构身份或修订不确定时展示不可比原因，不默认普通股、不将缺失值转换为零。
- 当前报告的未知身份行保留展示；不完整报告不能用于断言某证券已退出。
- 增加公司/CUSIP/类别搜索、变化筛选、上一期/下一期、边界禁用、当前筛选 CSV 导出。
- 导出保留机构、报告期、申报时间、证券身份、单位、变化限制和原文；中和电子表格公式。
- 未披露显示“不代表清仓”，新进显示“新披露”；继续说明季度滞后和权重口径。
- 表头随滚动固定，手机控制至少 44px，表格内部横向滚动，不挤出页面。
- 大型申报每页最多展示 100 行，搜索/季度切换回到第一页；CSV 导出全部筛选结果而非只导出当前页。

## 验证

新增测试先运行失败，再实现；单测检查缺失单位/股数、不同机构、日期、筛选/季度/导出和重复渲染。隔离 Chromium 使用样例报告验证交互，不把样例当作真实市场覆盖。完整测试、构建、Web/认证/四市场浏览器、安全扫描和 diff 检查后提交、推送、备份部署；正式域名验证版本、健康和功能区独占。

只操作 moneymoney.service；数据库、数据湖、scratch 和已有用户浏览器脚本保持原样。无子 agent、无实盘、无新增付费源。
