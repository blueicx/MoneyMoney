# 私人受限策略接入图表

本切片接续十二组平台路线第三批，不代表第三批或总路线完成。布局沿用现有图表图层面板，不新增工作区。

## 行为与边界

- 股票、虚拟币图表增加默认折叠的“已保存的私人研究策略”。管理员手动读取当前市场定义、选择固定版本或移除点位；没有自动策略请求、采集、模型调用、监控或订单。
- 图表复用当前完整K线和受限条件解释器，再由既有流程映射视窗、聚合标记、点击定位及展示OHLC、条件数值、来源、版本Hash和成熟观察。没有第二套行情。
- 当前切片只解释已完成K线，尚未完成的K线不生成自定义点位；日内缺口重新暖机。当前来源缺失/过期、周期不符、市场不符、格式不合法均明确拒绝；显式历史回放仍按时点上界排除未来数据。
- 手动选择固定到不可变版本，保存新版本不自动替换；切换标的、周期或工作区清除私人选择，需要重新选择。选择仅驻留内存，不写公开离线缓存。
- 股票点位身份改用当前已选标的身份，避免Provider的AAPL.OQ别名进入点位血缘。权限、请求取消及迟到响应检查沿用管理员与当前上下文约束。
- 解释器和适配器仅随图表模块加载；无独立首屏请求。现有跑单、策略审批、预算、模型路由和账户不改动。
