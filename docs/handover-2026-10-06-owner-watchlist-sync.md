# 管理员 Telegram 与网页自选同步

明确配置为管理员的私聊直接读取、添加、移除网页管理员的统一 SQLite 自选，不再维护第二份可编辑镜像。四市场仍按标的身份和当前市场过滤；其他私聊、群组及未配置管理员身份的聊天不继承网页私人自选。

首次绑定合并管理员原 Telegram 自选，使用既有标的解析规范化并去重。无法解析的旧记录原样保留在历史状态，不猜测市场。迁移标记持久化，重启或网页删除后不会把旧记录重新加回。新增管理员绑定通过动态配置判定，未配置管理员列表时不开放共享。

所有 Telegram 添加与删除入口都经 command-center 的共同方法，不直接绕过聊天身份写网页自选。股票信号扫描与摘要同样读取该入口。网页变化在下一次 Telegram 查询可见；Telegram 变化在网页刷新时可见。已启动 AI 跑单的冻结自选实验范围不随自选变更而改变。

发布沿用完整测试、Web/认证/浏览器冒烟、安全扫描、dist 备份和 Hash 校验，仅操作 moneymoney.service，保留用户数据库和数据湖。不以 API 状态冒充真实 Telegram 消息投递验收。
