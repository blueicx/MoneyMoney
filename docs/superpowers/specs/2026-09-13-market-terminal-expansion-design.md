# MoneyMoney 多市场终端扩充与布局优化设计

> 设计日期：2026-09-13  
> 设计状态：已获用户确认

## 目标

在保持股票、期权、虚拟币、预测市场和总体工作区隔离的前提下，扩充四市场研究能力，修正左侧功能区、中间工作区和右侧标的库的职责边界，并把新闻/事件来源做成可核查、可跳转的证据链。

最终用户路径为：

`选择市场 → 选择功能 → 选择标的/事件 → 查看数据与来源 → 筛选/比较 → 保存候选 → 回测/模拟/提醒`

## 当前基础与问题边界

当前系统已经具备市场作用域、左侧工作区导航、右侧股票及各市场标的库、免费数据源、K 线绘图、策略回测、模拟账本、提醒、AI 作用域和 Telegram 作用域。

本轮处理以下问题：

1. 中间区不能再显示固定七姐妹、BTC/ETH 或其他市场的重复标的卡片。
2. 右侧库必须承载固定标的、自选、搜索、候选和模拟持仓，并保持在右侧顶部。
3. 市场雷达、行情、事件和专属研究功能必须显示当前市场与当前标的的真实内容。
4. K 线必须能显示可选择的策略信号、蜡烛形态和指标，不再只有隐藏配置入口。
5. 新闻和事件必须显示来源、来源类型、时间、原文链接和来源状态。
6. 详情、筛选、比较、候选、回测、模拟和提醒必须保持同一 `market + workspace + instrument`。

## 布局契约

```text
┌──────────────┬──────────────────────────────────┬──────────────────┐
│ 左侧功能区   │ 中间唯一工作区                     │ 右侧标的/事件库     │
│              │                                  │                  │
│ 市场雷达     │ 当前市场 + 当前标的                 │ 固定热门标的        │
│ 行情与选股   │ 来源/更新时间/数据状态              │ 自选               │
│ 内部人交易   │ 当前功能内容                       │ 搜索               │
│ 分析师共识   │ K线/表格/研究卡/证据                │ 候选               │
│ …            │ 空状态/错误/重试                   │ 模拟持仓/事件库      │
└──────────────┴──────────────────────────────────┴──────────────────┘
```

- 左侧点击只改变 `workspace`。
- 右侧点击只改变 `instrument` 或事件上下文。
- 中间只渲染当前工作区，不渲染重复标的选择器、不渲染其他市场专属模块。
- 右侧库使用独立滚动区域；中心内容滚动时，右侧库保持在顶部并随页面滚动上下文可见。
- 工作区标题、数据状态、来源和重试入口位于中间内容顶部，避免用户误以为页面空白。
- 选中专属功能后直接展开内容，不再保留无关的折叠功能面板。

## 功能扩充矩阵

### 通用研究能力

- 全市场搜索、当前市场最近访问、收藏和候选库。
- 统一标的详情、同市场比较、研究笔记和来源快照。
- 按当前市场字段白名单筛选，保存筛选模板，批量加入候选。
- 从筛选或详情进入回测、模拟持仓和提醒，并保留来源与参数。
- 价格、策略、数据源异常和事件提醒，保留触发及投递记录。
- 新闻/事件日历、证据工作台和 AI 解释卡。
- 统一显示加载中、实时、延迟、缓存、部分成功、暂无数据和不可用状态。

### 股票市场

- 行情、指数、市场宽度、行业轮动和热门板块。
- 多周期 K 线、成交量、均线、RSI、MACD、布林带、支撑阻力。
- 日本蜡烛图形态与策略点位，支持单独开关和最近信号列表。
- 内部人交易、机构持仓、分析师评级/目标价/具体观点。
- 基本面质量、财报、估值、现金流、负债、分红和拆股。
- 空头利息、财报日历、重大事件和公司公告。

### 期权市场

- 期权链、到期日、行权价和流动性筛选。
- IV 期限结构、Skew、Greeks、GEX、PCR、Max Pain。
- 异常成交、到期风险、盈亏平衡点和策略 Payoff 图。
- 多腿策略构建器，支持策略说明、风险和进入回测的参数。
- 缺少历史 IV/Greeks 时返回不可用状态和明确数据需求，不生成伪结果。

### 虚拟币市场

- 多周期 K 线和可选策略点位。
- 资金费率、未平仓量、爆仓、多空比、盘口深度和主动资金流。
- 多交易所价差、链上活跃度、BTC 难度、ETH Gas。
- 稳定币流动性、DeFi TVL、协议排名和链排名。
- 行情新闻、链上事件、价格/资金费率/波动异常提醒。

### 预测市场

- 事件筛选、概率历史、概率变化、成交量和流动性。
- YES/NO 订单簿、价差、截止时间、事件树和情景分析。
- 结算规则、结算证据、解析状态和争议状态。
- 校准曲线、Brier 分数、历史命中率和模型复盘。
- 预测市场专属候选、回测和提醒，禁止混入股票或虚拟币字段。

## K 线策略与形态设计

股票和虚拟币使用同一策略信号契约：

```ts
type ChartSignal = {
  index: number;
  time: number;
  side: 'buy' | 'sell';
  strategy: string;
  label: string;
  price: number;
  reason: string;
};
```

策略开关至少包括：

- 均线交叉：MA5/MA20 金叉和死叉。
- RSI 反转：RSI 收复 30 或跌破 70。
- 布林反转：价格重新站回下轨或跌回上轨。
- 放量突破：相对近期均量出现放量并伴随方向变化。

显示层支持独立控制：策略点位、蜡烛形态、结构标记、均线、布林带、成交量。图上显示方向箭头和策略名称，图下显示最近信号的日期、价格和触发理由。旧版本地配置缺少新字段时自动合并安全默认值。

股票当前以日线数据刷新策略；虚拟币按当前 K 线周期刷新策略。两者均不把计算信号描述为保证性买卖建议。

## 新闻、事件与来源证据

所有新闻和事件统一使用：

```ts
type SourceEvidence = {
  title: string;
  sourceName: string;
  sourceType: 'media' | 'official' | 'company' | 'market-data' | 'prediction';
  sourceUrl: string;
  publishedAt: string | null;
  fetchedAt: string;
  sourceStatus: 'live' | 'delayed' | 'cached' | 'unavailable';
};
```

卡片展示：

```text
标题
来源：BBC · 媒体 · 2026-09-13 08:30
[查看原文 ↗]
```

实现规则：

- BBC、Reuters、Bloomberg 等媒体显示媒体来源。
- 美联储、SEC、FRED、财政部等显示官方来源。
- 公司 IR、财报和公告显示公司来源。
- Nasdaq、Binance、CoinGecko 等显示市场数据来源。
- 预测市场规则页和结算页显示预测市场来源。
- 原文使用新标签页打开，并设置 `noopener noreferrer`。
- 标题、来源 URL 和发布时间用于去重，避免同一事件重复出现。
- 原文失效时保留标题、来源和抓取时间，并显示来源不可用。
- AI 解读、提醒和研究笔记保留相同来源链接，不能只显示没有出处的总结。

## 数据流与状态

```text
市场切换
  ↓
workspace + instrument 上下文
  ↓
取消旧请求并清空旧工作区
  ↓
当前功能接口 + 当前市场数据源
  ↓
data + status + source evidence
  ↓
中心工作区渲染 / 右侧库同步
```

每个请求必须带市场作用域；切换市场或标的后，旧请求即使晚返回也不能回填当前 DOM。数据状态至少区分：实时、延迟、缓存、部分成功、暂无数据和不可用。选项历史链、预测市场结算证据等关键数据缺失时，显示原因和重试/数据需求，不回退到其他市场。

## Antigravity 与 Codex 职责

- Antigravity：在明确项目根目录和工作区内探索现有实现，拆分可复用模块，实现功能，补充单元/接口/浏览器测试，并提交执行证据。
- Codex：审核探索报告和变更范围，检查市场隔离、数据来源、权限、缓存和布局契约；独立运行测试、构建、安全扫描和浏览器矩阵；确认备份、远端 Hash、健康接口后上传。
- Antigravity 不负责最终发布，不修改 Nginx、TLS、VPN、密钥或 Telegram 轮询所有权。
- Antigravity 报告“完成”不等于验收完成；必须同时具备实际 diff、测试结果和可复现浏览器证据。

## 测试与验收

### 自动化测试

- 四市场工作区和右侧标的库的 DOM 边界测试。
- 市场/工作区/标的切换后旧请求不能回填。
- K 线策略信号包含方向、策略名、价格、时间和触发理由。
- 旧 K 线配置能补齐策略默认值，用户选择可以持久化。
- 新闻/事件必须有来源字段、原文 URL、安全跳转属性和来源状态。
- 筛选、比较、候选、回测、模拟和提醒保持同一市场作用域。
- 不可用数据返回明确原因，不使用其他市场数据伪造。
- Guest 公开 GET 与所有写操作权限边界保持不变。

### 浏览器验收矩阵

- 股票：行情、市场雷达、事件、内部人、分析师、基本面、K 线信号。
- 期权：期权雷达、期权链、IV/Greeks、策略构建器和右侧期权库。
- 虚拟币：行情/K线、资金费率、OI、链上、主动资金流和右侧币种库。
- 预测市场：预测雷达、概率历史、事件证据和右侧事件库。
- 每个市场验证右侧库位于顶部，中心只显示选中的功能。
- 每个新闻/事件验证来源名称、来源类型、时间和“查看原文”跳转。
- 至少验证一类 K 线策略点位真实出现在图上和信号列表中。

### 发布门

只有以下条件全部满足才上传：

1. `npm test` 全部通过。
2. `npm run build`、`npm run smoke:web`、`npm run security:scan` 和 `git diff --check` 通过。
3. 真实浏览器验证四市场工作区、标的选择、K 线点位和来源跳转。
4. 远端应用产物 Hash 与本地构建一致，健康接口正常。
5. 已备份 `/opt/moneymoney/dist`，发布失败可回滚。
6. 未修改 Nginx、TLS、VPN、密钥或 Telegram 轮询配置。

## 非目标

- 不接入真实交易或真实持仓同步。
- 不把 AI 输出直接转为真实订单。
- 不用付费数据源替代免费源作为必需依赖。
- 不复制第三方项目源码、品牌或受限资源。
- 不为了增加功能再次把多个市场模块堆叠到同一个中间区。
