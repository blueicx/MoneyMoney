# 市场作用域彻底隔离设计

## 目标

当前选择的市场必须决定分析、风险、持续信息和市场专属工具的数据边界；宏观作为跨市场背景移动到通用工具栏。首页（总体）继续允许跨市场汇总。

## 设计

### 作用域边界

- `overview`：显示跨市场汇总。
- `stocks`：仅股票与股票行业相关分析、风险、持仓和持续信息。
- `options`：仅期权策略、期权风险与期权持续信息。
- `crypto`：仅加密资产分析、风险与加密持续信息。
- `prediction`：仅预测市场分析、风险与预测市场持续信息。
- `watchlist`：显示统一自选中的标的，按标的实际类型过滤相关内容。
- 宏观数据不再挂靠股票页，迁移为通用工具栏入口；它可以显示全球宏观背景，但不改变当前市场的专属数据集合。

### 分析与风险

服务端统一接收 `scope`，在生成响应前过滤行动、提醒、风险信号、主题集中度、预测雷达和纸面账本。客户端只渲染当前作用域允许的分区；空分区不显示空壳标题。风险历史、校准和导出请求也携带作用域，避免页面虽然过滤而接口仍返回全局数据。

### 持续信息

持续信息加载器在读取初始市场作用域后运行，并使用作用域参数选择对应源。无对应源时隐藏 ticker 或显示当前市场暂无持续信息，不复用加密 ticker。切换市场会使旧请求失效，防止异步响应覆盖新市场。

### 兼容与失败处理

没有作用域参数的现有 API 保持原有总体行为；非法作用域回退为总体。单一数据源失败只影响对应卡片，页面仍显示其他已成功数据。访客仍只读，真实交易和 AI 自动下单保持禁用。

## 验证标准

- 分析页在股票、期权、虚拟币、预测市场之间切换时，不出现其他市场的标题、卡片或数据。
- 风险页的指标、主题、历史、校准和导出都遵循当前作用域。
- 期权页不再出现 BTC/ETH/DeFi ticker；其他市场不出现不属于自己的 ticker。
- 宏观只能从通用工具栏打开，并且仍可作为跨市场背景查看。
- `npm test`、`npm run build`、`git diff --check` 通过，浏览器验证至少覆盖股票、期权、虚拟币三种作用域。
