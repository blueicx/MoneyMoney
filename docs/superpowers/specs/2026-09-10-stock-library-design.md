# 股票自选库与持仓库设计

## 目标

让“自选”市场显示真实的统一自选标的，并让股票市场右侧栏从预测市场的“选择事件”切换为股票标的库。当前只启用股票模拟持仓，真实持仓保留明确的未接入状态。

## 交互与数据流

- 自选页在“我的持仓”上方增加“我的自选”，读取 `GET /api/watchlist`，仅将 `stock:us:*` 渲染为股票条目，其他市场维持各自统计与入口。
- 股票市场右侧栏显示“我的自选”“模拟持仓”“真实持仓（暂未接入）”三组。模拟持仓读取 `GET /api/paper/positions?scope=stocks`，不读取或伪造真实交易数据。
- 点击任意股票条目统一调用股票选择入口，设置当前股票并刷新行情、K 线、内部人、机构持仓、分析师、基本面和空头雷达；不会把标的转成预测事件。
- 空列表、接口失败和访客模式分别显示只读、暂无数据和暂不可用提示；修改自选仍由现有管理员权限控制。

## 实现边界

优先复用现有 `/api/watchlist`、统一纸面账本和 `selectStockSymbol`，不新增真实交易接口，不改变 Nginx、证书、VPN 或 Telegram 数据结构。预测市场仍使用原事件侧栏。

## 验收标准

1. 自选页能看到实际股票自选，且位于我的持仓之前。
2. 股票市场右侧栏标题和内容是股票标的库，不再显示预测事件提示。
3. 自选和模拟持仓中的股票点击后，股票行情及七个相关股票数据区使用同一股票。
4. 访客不能修改自选或模拟账本；真实持仓不显示虚构记录。
5. 相关回归测试、构建、完整测试、密钥扫描和浏览器点击验收通过。
