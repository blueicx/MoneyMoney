# 独立功能工作区扁平面板设计

## 背景

当前市场页面在进入内部人交易、机构持仓、分析师共识、基本面质量、空头利息等独立功能后，功能内容仍包在带背景、边框和折叠箭头的外层面板中。用户已经通过左侧功能导航明确选择了功能，重复的折叠交互增加了视觉噪声，也让页面看起来像仍然包含多个待选择模块。

## 目标

1. 进入独立功能工作区后，中间区域直接呈现该功能的完整内容。
2. 去掉中间功能面板的外层边框、背景块和折叠箭头。
3. 保留功能标题、说明和刷新入口，但改为轻量的扁平工具栏。
4. 保留真正承载数据的内部内容框、卡片、表格和数据状态提示。
5. 所有市场采用一致规则，避免只修复股票内部人交易造成界面不一致。

## 设计范围

### 独立功能工作区

以下工作区在被选中时使用扁平面板：

- 股票：市场宽度、内部人交易、机构持仓、分析师共识、基本面质量、空头利息。
- 期权：期权链、波动率、Greeks。
- 虚拟币：资金费率、未平仓量、链上数据、主动资金流与盘口。
- 预测市场：预测雷达。
- 通用研究：回测、分析、风险、自选和持仓等已有独立工作区。

独立工作区只显示当前功能内容，其他工作区继续由现有作用域和工作区可见性逻辑隐藏。

### 保留的折叠能力

- 总览页继续保留模块外框、标题和折叠能力，因为总览需要同时容纳多个市场模块。
- 左侧“市场功能区”继续保留整体收起/展开能力。
- 数据内容内部已有的必要交互（例如下拉选择、筛选、回放和表格分页）不属于本次要移除的面板折叠。

## 视觉与交互规则

1. 独立功能页移除顶层 `details` 的外层背景、边框、圆角和折叠指示器。
2. 顶层功能标题保留为扁平工具栏；刷新按钮放在同一工具栏内，不依赖折叠状态。
3. 顶层功能内容默认完整可见，不显示“展开/收起”提示，也不能通过标题收起。
4. 数据卡、明细列表、表格和错误/不可用提示继续使用现有内容框样式，确保数据层级仍清晰。
5. 移动端保持现有响应式布局；工具栏允许换行，但不引入横向滚动作为唯一操作方式。

## 实现边界

- 复用现有 `dash-collapse` 和 `applyWorkspaceView()` 的作用域判断，不改变市场数据请求、缓存、取消请求或错误降级逻辑。
- 为独立工作区增加统一的展示状态/样式钩子，避免逐个页面编写互不一致的 CSS。
- 顶层功能面板保留可访问名称；移除折叠后不再声明可展开控件。
- 不修改市场导航、右侧标的库、七姐妹快捷入口、自选/持仓数据模型和后端 API。

## 数据流与状态

工作区切换仍由现有导航流程完成：更新市场和工作区上下文 → 应用作用域可见性 → 加载当前标的数据 → 加载当前功能数据。面板的扁平化只影响渲染层，不改变请求顺序或响应处理。

当数据源返回不可用、缓存或错误状态时，继续在内部内容框中显示现有状态说明；不能因为移除外层面板而吞掉错误、伪造数值或改变来源标签。

## 测试与验收

### 自动化测试

- 独立工作区面板不再包含顶层折叠箭头或可收起标题。
- 独立工作区仍声明正确的市场范围和工作区范围。
- 总览页仍保留折叠模块及“全部展开/全部收起”能力。
- 左侧功能导航仍可收起/展开。
- 现有市场隔离、数据源状态、股票选择、回测和 K 线覆盖不回归。
- HTML 内联脚本语法、构建、完整测试、安全扫描和 Web smoke 全部通过。

### 浏览器验收

至少检查股票内部人、机构、分析师、基本面、空头，期权链，虚拟币资金费率，以及回测/分析/风险工作区：

- 当前功能内容直接可见；
- 没有中间面板折叠箭头和外层大框；
- 内部数据框仍存在；
- 切换标的后当前功能仍显示新标的数据；
- 总览页仍能折叠和展开模块；
- 左侧功能导航仍能收起和恢复。

## 非目标

- 不删除任何数据内容或功能入口。
- 不把所有内部卡片压成无边界文本。
- 不移除总览页的模块折叠。
- 不修改 VPS、Nginx、证书、Telegram 轮询或密钥配置。
