# 右侧股票标的库设计

## 目标

在股票市场的所有工作区中，将“选择标的”与“研究功能”彻底分离：右侧固定显示股票标的库，中间只显示当前选中的市场功能内容。七姐妹、自选、模拟持仓和搜索结果都在右侧完成选股，点击后只刷新中间当前功能的股票数据。

## 现状与边界

- 当前页面已有右侧 `.sidebar` 和 `#stock-instrument-library`，但只显示自选与模拟持仓。
- 七姐妹、搜索和加入自选仍分散在行情区及每个股票雷达的正文工具栏。
- `applyWorkspaceView()` 已负责隐藏非当前工作区正文模块，本次只扩展选股入口与选择后的加载路由。
- 只改股票市场选择层；期权、虚拟币和预测市场保留现有各自内容。
- 访客可以读取七姐妹、自选、模拟持仓和搜索结果；“加入自选”继续由现有访客只读策略阻断。

## 方案

复用现有右侧 `.sidebar`，扩展 `#stock-instrument-library` 为完整的股票标的库，分为：

1. 当前标的摘要与当前工作区提示。
2. “美股七姐妹”快捷按钮。
3. 搜索输入、搜索按钮与搜索结果列表。
4. 我的自选列表。
5. 模拟持仓列表。
6. 真实持仓未接入提示。

中心 `#stocks-tab` 删除行情区的七姐妹/自选/加入自选/搜索控件，并删除五个股票雷达工具栏中重复的选择和搜索控件；雷达保留自己的刷新按钮和数据正文。七姐妹与搜索结果统一调用 `selectStockFromInstrumentLibrary()`，该函数先保存当前股票，再根据 `activeWorkspaceId` 调用当前功能对应的 loader；不会切换到“行情与选股”或“热门股票”页面。

## 数据流与错误处理

- 标的库加载复用 `stockLibraryData()` 的请求缓存，七姐妹为静态配置，搜索复用 `/api/stock/search`。
- 选择标的时保留当前市场和工作区 URL 参数，更新 `instrument`，并只调用当前功能 loader；`overview` 才加载统一股票行情和 K 线。
- 搜索空值、无结果、网络失败分别在右侧结果区域显示明确状态，不污染中心正文。
- 选择自选或模拟持仓使用同一选择入口，保证所有来源行为一致。

## 验收标准

1. 股票总览及六个股票专属工作区都能看到右侧标的库。
2. 右侧包含七姐妹、搜索、自选和模拟持仓；中心不再出现重复的七姐妹、自选、加入自选和搜索控件。
3. 在内部人、机构持仓、分析师共识、基本面质量或空头利息工作区点击七姐妹、搜索结果、自选或模拟持仓后，URL 仍保持原 `workspace`，中心只保留该工作区且数据请求使用新标的。
4. 返回总览后中心恢复股票总览模块；切换到期权、虚拟币或预测市场后股票标的库隐藏。
5. 访客搜索和读取标的库成功，加入自选仍不产生写入。
6. 自动化测试、构建、完整测试、安全扫描和 Playwright 浏览器 smoke 全部通过。
