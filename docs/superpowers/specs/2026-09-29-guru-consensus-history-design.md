# 13F 跨机构重合与多季度趋势设计

**日期：** 2026-09-29
**状态：** 方案已获用户确认，待书面规格审阅
**范围：** MoneyMoney 股票工作区“大神持仓”的只读研究视图

## 1. 目标与边界

复用现有 SEC Form 13F 报告快照，增加两种可相互跳转的分析：

1. 按报告期查看哪些已跟踪申报主体披露了同一证券，以及各自披露股数的变化状态。
2. 按申报主体查看最近最多四个实际可用报告期的持仓历史。

这是公开披露的检索和描述性统计，不生成“聪明钱评分”、买卖信号、投资建议或订单。13F 是滞后且不完整的季度披露；页面始终显示报告期、申报时间、样本覆盖和“非实时仓位”说明。

## 2. 数据口径

- 数据仅来自 `research.db` 中已保存且通过校验的 SEC 13F 快照；浏览分析页不触发 SEC 请求。
- 同一申报主体、报告期存在修订时，沿用现有有效申报/修订规则；无法安全解释的修订期标为不可比较，不混入有效统计。
- 跨机构重合按相同 `reportPeriod + CUSIP + classTitle + putCall` 分组。证券代码只使用已核验映射；未映射证券显示申报名称和 CUSIP，不猜测 ticker。
- 报告期必须完全相同才可汇总。不同报告期分开展示；选择报告期时明确列出有效申报主体数和不可用/缺报数，不以其他季度填充。
- 持仓变化仅由同一机构相邻有效报告期的披露股数计算。市值变化不用于推断买卖；前期有而本期缺失只标“本期未披露”，不称清仓。
- 多季度趋势显示每期披露股数、申报市值和申报链接。市值仅是申报文件报告值，不折算成当前市值或账户净资产比例。
- 样本不齐、快照过期或修订关系不确定时保留可验证行，同时显式显示部分/不可比较状态和原因。

## 3. 用户体验

在现有“投资人持仓”和“热门股票持有人”视图旁新增“机构重合”视图。用户可选报告期、股票代码/证券、申报主体；结果表展示证券身份、披露主体数、各主体名称、报告股数、相邻期变化状态及 SEC 原文链接。点主体进入其完整持仓/历史，点已映射股票跳转股票工作区并保留所选报告期上下文。

投资人详情增加“历史报告”区，默认展示最近最多四个已持久化的有效报告期；每个期间可展开持仓行和来源。若目前只存有一至两个期间，照实展示覆盖数，并显示历史快照尚未积累/回补的状态，不造出空季度或插值数据。

使用现有主题、三栏布局和访客只读边界。无有效同周期报告时分别说明“当前没有共同报告期”“该期来源不可用”“该期暂无匹配证券”，避免统一成“暂无持仓”。

## 4. 历史数据积累与 API

复用现有 13F 刷新服务、SEC 限流、按 CIK 租约和 `guru_13f_reports` 表。把每个精选申报主体的历史检查范围从两个最新报告期扩至最多四个不同报告期；只下载本地尚未保存的文件。刷新仍串行、低频并受现有 SEC 节流约束；失败保留已缓存结果和逐份失败原因，后续可重试，不因旧报告失败丢弃新报告。页面读 API 时只读取持久化快照。

新增只读接口：

- `GET /api/stocks/guru-holdings/consensus?reportPeriod=&symbol=`：返回精确报告期内按证券身份聚合的披露主体和变化摘要，并给出覆盖计数、来源状态及证据链接。
- `GET /api/stocks/guru-holdings/managers/:cik/history?limit=4`：返回该申报主体最近最多四个有效报告期及每期来源、申报信息和持仓数据。`limit` 服务端限制为 1–4。

响应继续携带股票市场、报告期、数据状态、更新时间、来源、原因和证据引用。访客可以读取公开 SEC 披露；强制刷新仍为管理员权限。查询不跨市场、不请求外部 CIK 任意 URL，也不触及私人组合和模拟盘。

## 5. 测试与验收

- 同报告期同 CUSIP/类别/put-call 才重合；不同季度、不同证券类别和 put/call 不得被合并。
- 披露主体缺报、来源失败、缓存过期和修订不可比较均反映在覆盖计数/状态中，不以别的季度补齐。
- 趋势最多四个不同有效报告期；修订文件不会被当作独立季度；旧报告失败不清除已保存的新报告。
- 股数变化、申报市值变化和“本期未披露”标签遵循上述语义。
- API CIK、报告期、股票标识和 `limit` 校验；访客只读，管理员刷新边界不变。
- 浏览器验收：投资人到历史报告、股票到机构重合、SEC 原文跳转、报告期切换、窄屏表格和空/部分/失败状态。
- 通过项目的测试、构建、Web/浏览器/认证冒烟、安全扫描和差异检查后，才进入代码交付与部署。

## 6. 后续阶段（本规格不包含）

“全做”中的另外两项继续单独设计和验收：

1. 在 SEC 身份、真实 13F 申报和人物关联均核验后，逐步扩大精选申报主体；不按名气猜测 CIK 或个人归属。
2. 补强逐标的行情、新闻、内部人和事件覆盖，明确区分成功无记录、来源失败、缓存、过期和市场不支持。

本规格只涵盖第一项 13F 分析批次，不把后续两项混入同一实现计划。
