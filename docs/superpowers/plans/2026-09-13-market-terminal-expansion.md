# MoneyMoney 多市场终端扩充与布局优化实施计划

> 对应规格：`docs/superpowers/specs/2026-09-13-market-terminal-expansion-design.md`
> 
> 执行方式：Antigravity 负责探索与实现，Codex 负责计划、监督、复测、发布。

## 目标与完成定义

将股票、期权、虚拟币、预测市场和总体工作区统一到清晰的三栏交互模型：

```text
左侧功能区（workspace） → 中间唯一工作区（当前功能） ← 右侧标的/事件库（instrument/event）
```

完成后必须满足：

- 中间区只显示当前市场、当前功能和当前标的的内容；固定七姐妹、BTC/ETH、期权标的等选择项不再重复出现在中间。
- 左侧功能切换只改变 `workspace`，右侧点击只改变 `instrument` 或事件上下文。
- 四个市场均有可用的市场雷达、专属行情/研究入口、空状态和数据源状态；不可用时明确显示原因和重试入口。
- K 线能够显示策略信号和日本蜡烛图形态，并允许用户分别开关显示项，信号有日期、价格、理由和来源/计算状态。
- 新闻/事件显示来源、来源类型、发布时间、数据更新时间、原文链接和链接状态；原文链接安全打开并支持失效来源提示。
- 所有详情、筛选、比较、候选、回测、模拟和提醒均保留同一 `market + workspace + instrument` 上下文。

## 执行约束

- 先探索现有路由、DOM、数据适配器和测试，再修改；不得凭截图重写页面。
- 遵守现有用户未提交文件：`docs/antigravity-plans/2026-09-11-money-next-batch.md`、`docs/notes/`、`tests/kline-upgrade.test.cjs` 不得覆盖、删除或代提交。
- 采用小批次、可回滚提交；每个批次先补失败测试，再实现，再跑对应回归测试。
- 不实现真实下单、自动投资建议或 AI 自动下单；不引入必须付费的行情源；不复制参考项目代码。
- 不修改 Nginx、TLS、VPN、生产密钥、Telegram 轮询配置或服务器基础设施配置。

## 阶段 1：三栏布局与右侧标的库

### 任务

1. 左侧仅保留功能入口，并按“市场 / 研究 / 当前市场专属”分组；移除不必要的组合框和独立外框。
2. 中间只保留当前功能内容；选中功能后直接显示完整内容，不再堆叠无关折叠面板。
3. 右侧库统一承载固定热门标的、自选、搜索、候选、模拟持仓和事件入口。
4. 为股票、期权、虚拟币、预测市场分别提供同构的右侧库组件/数据模型。
5. 右侧库在桌面端保持顶部可见并独立滚动；窄屏切换为可展开抽屉，始终有明显的打开入口。
6. 处理“点击右侧标的后中间没有内容”的问题：路由、选择态、加载态、错误态和空态必须可见。

### 主要文件范围

- `src/web/public/index.html`
- `src/web/public/*.js`
- `src/web/server.ts` 及现有市场服务/路由文件
- `tests/market-terminal-layout.test.cjs`
- `tests/market-navigation-wiring.test.cjs`
- 新增必要的布局/上下文测试

### 验收

- 四市场逐一点击右侧固定标的、自选、搜索结果，中心均出现对应标的标题和数据状态。
- 进入行情、事件、内部人、机构持仓、分析师、基本面、市场雷达等功能时，中间不出现其他功能面板或重复标的卡。
- 右侧收缩后可从固定入口恢复；滚动中心内容时右侧库按规格可见。
- `npm run build && npm run smoke:web`

## 阶段 2：数据源、新闻与事件证据链

### 任务

1. 统一 `SourceEvidence`：标题、来源名、来源类型、原文 URL、发布时间、抓取时间、来源状态。
2. 新闻/事件卡提供“查看原文 ↗”，使用安全链接属性；无效 URL 仍保留来源文本和状态，不渲染危险协议。
3. 建立来源白名单/分类：BBC、Reuters、Bloomberg、Federal Reserve、SEC、FRED、Treasury、公司 IR、Nasdaq、Binance、CoinGecko 等；对不可用源显示具体状态。
4. 去重同一事件，保留多来源；支持按来源类型、时间和当前标的筛选。
5. 为分析师观点、内部人/机构申报、财报、预测市场结算证据统一挂载来源。
6. 修复“市场雷达始终无信息”的误判：区分“确实暂无事件”“数据源不可用”“部分来源成功”“加载失败”。

### 主要产物

- 统一事件/新闻 DTO 与适配器映射。
- 来源证据组件和链接安全测试。
- 四市场的空状态/部分成功/错误状态。

### 验收

- 新闻卡能显示来源和原文链接；点击链接打开正确 URL，不丢失上下文。
- 模拟源、失效源、空结果、部分成功分别显示不同状态。
- `npm test -- --test-name-pattern="event|source|news|timeline|evidence"`

## 阶段 3：K 线策略信号与日本蜡烛图形态

### 任务

1. 保留并扩展统一 `ChartSignal`：时间、方向、策略、标签、价格、解释和计算状态。
2. 策略点位支持均线交叉、RSI 反转、布林带反转、放量突破，并为股票/虚拟币适配时间周期。
3. 增加日本蜡烛图形态：十字星、锤头线、上吊线、吞没、刺透/乌云盖顶、早晨/黄昏之星、三白兵/三只乌鸦、孕线、长影线等；每个形态提供方向、置信度、识别条件和免责声明。
4. 提供分组开关：策略信号、蜡烛形态、趋势指标、成交量/波动率；默认少量显示，避免图表混乱。
5. 图上标记与下方列表双向定位；列表显示日期、价格、信号理由和数据时间。
6. 历史数据不足、周期不支持或源延迟时，明确显示不可计算原因。

### 主要文件范围

- `src/web/public/chart-analysis.js`
- `src/web/public/index.html`
- `tests/chart-analysis.test.cjs`
- `tests/kline-upgrade.test.cjs`
- 新增形态/信号测试

### 验收

- 股票和虚拟币各打开一个 K 线，能看到真实蜡烛、独立开关和至少一类信号列表。
- 切换策略/形态开关后只更新对应图层，不丢失当前标的和周期。
- 信号列表与图上标记数量/方向一致；刷新后偏好可恢复。
- `npm test -- --test-name-pattern="chart|kline|strategy|pattern"`

## 阶段 4：研究功能扩充

### 股票

- 行情、指数、宽度、行业轮动、筛选器、详情、比较。
- 内部人申报、机构持仓、分析师姓名/机构/评级/目标价/观点原文。
- 基本面质量、估值、现金流、负债、财报、分红、拆股、空头利息和事件日历。

### 期权

- 期权链、到期/行权价/流动性筛选，IV 期限结构与 Skew。
- Greeks、GEX、PCR、Max Pain、异常成交、盈亏平衡和 Payoff 图。
- 多腿策略构建器和进入回测的参数快照；数据不可用时显示边界而非伪造数据。

### 虚拟币

- 多周期 K 线、资金费率、未平仓量、爆仓、Long/Short、订单簿和深度。
- 交易所价差、交易流、链上指标、BTC 难度、ETH Gas、稳定币、DeFi TVL、排名、新闻和提醒。
- BTC/ETH 等固定标的只在右侧库出现，中间仅显示当前选中标的。

### 预测市场

- 事件列表、概率历史、成交量/流动性、订单簿、结算证据和结算时间线。
- 预测复盘、校准曲线、Brier 分数和来源证据；不可用市场清楚标注原因。

### 通用研究循环

所有研究页统一提供：筛选 → 详情 → 比较 → 加入候选 → 笔记 → 回测/模拟 → 提醒，并保留参数和来源快照。

### 验收

- 每个市场至少有一个真实可用的详情/研究工作区和一个空/不可用状态演示。
- 分析师卡必须能显示具体分析师/机构、观点、评级、目标价、日期和来源。
- `npm test -- --test-name-pattern="research|screener|compare|analyst|fundamental|options|crypto|prediction"`

## 阶段 6：回归、发布与监督

### Codex 监督流程

1. Antigravity 完成每个阶段后提供变更摘要、测试输出和已知限制。
2. Codex 检查实际 diff、运行定向测试和全量测试，必要时要求 Antigravity 修复；不接受只报告“完成”而没有证据。
3. 发布前执行构建、冒烟、安全扫描，并在真实浏览器验证五类市场的关键路径。
4. 通过后提交、推送、备份远端部署目录，健康检查成功后再向用户报告；失败则保留回滚点并停止发布。

### 必跑命令

```powershell
npm test
npm run build
npm run smoke:web
npm run security:scan
```

### 浏览器验收路径

```text
股票：右侧 AAPL → 行情/选股 → 详情 → K线策略/形态 → 新闻原文
股票：右侧 AAPL → 内部人/机构/分析师 → 具体人员/机构观点与来源
期权：右侧 SPY → 期权链 → 到期/行权价 → Payoff/回测
虚拟币：右侧 BTC/USDT → K线/资金费率/深度 → 刷新
预测市场：右侧事件 → 概率/历史/结算证据 → 原文链接
```

### 发布门

- 全量测试和构建均通过。
- 关键浏览器路径没有中心空白、跨市场串数据、重复标的或失效入口。
- 所有新增外部链接经过 URL 安全校验，来源状态可解释。
- 远端健康检查返回 `ok: true`，部署版本与本地构建版本一致。
