- [x] 公司行动：UnifiedPaperLedgerStore 增加事务回滚预览，使用同一实际同步路径；`POST /api/paper/accounts/:id/reconcile/preview` 返回账户、现金/数量/成本变化、来源事件与摘要 Hash。确认时服务器重算并核对 Hash/有效期，源账户、跑单或目录变化返回 409；确认与审计在原事务中保存。保留旧 API 兼容，网页只用带预览确认的新流程。
- [x] 数据健康/恢复：只覆盖已登记期权快照 JSON，读取目录检查文件、语义内容 Hash、身份和备份 manifest。管理员接口只接收快照 ID 和备份 ID，不接收物理路径；预览后确认，保留损坏原件，只从 Hash/语义完整匹配的副本恢复单文件。没有可靠副本返回未知，禁止全库还原、猜测合并、自动采集。源/目标路径不可越界或穿越 symlink。嵌入原数据资产面板。
