# 使用新增图表策略

这些点位仅用于研究，不是订单，也不承诺盈利。新增策略默认关闭；不会改变现有 AI 跑单、Telegram 扫描或自动创建交易。

## 打开与调整

进入股票或虚拟币 K 线，展开 **更多策略与参数（9 类 + 严格放量 v2）**。每项有独立开关；展开该项“参数与条件”可修改参数。非法参数会恢复上次有效值并显示原因，不会保存错误配置。

参数沿用已有图表偏好存储：股票按现有市场/标的键，虚拟币按标的/周期键。切换市场不会启用另一市场的策略。图表信号筛选可按策略、方向、形成中/已确认查看。

点击点位或解释列表，查看触发价、时间、OHLC、规则原因、策略版本、规范化参数及来源。后续 1/3/5/20 根表现只在相应 K 线完成后成熟；缺口、未成熟或未提供成本假设都会明确说明，不补零收益。

## 规则与默认参数

| 策略 | 默认参数 | 触发条件 |
|---|---|---|
| MACD 金叉/死叉 | 12 / 26 / 9 | SMA 初始化 EMA，MACD 穿越信号线 |
| EMA 趋势回踩 | 20 / 50 | 快慢 EMA 顺序及快线斜率同向，收盘重新穿越快线 |
| 唐奇安通道突破 | 20 根 | 收盘严格突破此前 N 根最高价/最低价，不包含当前根 |
| 布林收窄突破 | 20 根、2 倍标准差、带宽 ≤ 4% | 前一根窄带后，收盘突破前一根轨道 |
| 随机指标反转 | %K 14、%D 3、20/80 | 原始 %K 与 SMA(%K) 交叉，上一根在超卖/超买区 |
| CCI 反转 | 20 根、±100 | 典型价与平均绝对偏差，系数 0.015；收复负阈值/跌破正阈值 |
| OBV 量价确认 | 20 根 | 收盘突破此前高低点，OBV 同向突破此前区间极值 |
| ATR 通道突破 | EMA20 / Wilder ATR14 / 2 倍 | 收盘突破上一根 EMA ± ATR 倍数；当前冲击不改变本根阈值 |
| 日内 VWAP 收复/跌破 | 至少 3 根会话 K 线 | 成交量加权典型价 `(H+L+C)/3`；收盘穿越累计 VWAP |
| 严格放量突破 v2 | 20 根、1.5 倍均量 | 同时满足此前高低点突破和此前区间成交量倍数 |

周期类参数为 2–250 整数；倍数与阈值在控件中显示实际范围。MACD/EMA 的快线必须小于慢线。不同规则及参数独立生成版本化点位 ID，不混为同一个实验结果。

旧 `volumeBreakout` 仍按原有“放量涨跌”规则计算，控件明确标为旧版，其信号标签、旧版本和历史 ID 不变。严格突破为 `volumeBreakoutV2`，不会重写旧结果。

## 数据限制

- 股票和虚拟币复用各自图表的完整已加载数据，再映射到缩放视窗；无新增行情通道，不跨市场补数据。
- 未收线实时点位沿用空心形成中；收线确认后实心。来源过期时停止形成中预览，缓存不能被称为逐笔实时。
- OHLC 无效、空记录、重复/倒序时间会拒绝新增策略计算。OBV、VWAP、严格放量策略额外要求真实有效的成交量。暖机不足会说明需要多少根。
- VWAP 仅支持 1/5/15 分钟和 1 小时。虚拟币以 UTC 00:00 为日会话起点；股票只在来源明确给出受支持交易所时区时，以当地 09:30 为累计起点。它包含来源起点后提供的后续时段，不声称是完整常规交易时段统计。
- 必须实际覆盖起点；VWAP 会在日内时间缺口后停止累计，不把视窗首根、午间缺口或停牌缺口伪装成完整会话，也不插值。来源不支持时显示具体原因。
- 所有新实现只向前计算，后来的 K 线不参与此前入场条件。来源修订、复权口径或加载更早的 EMA 暖机历史仍可能影响重算，重现研究必须保留对应数据与参数。
