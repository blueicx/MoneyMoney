# 合约研究与工作流增强验收

## 本批交付

- 虚拟币市场新增“永续与交割合约”：右侧真实来源目录、类型选择与搜索；中间仅展示选中合约的标记/指数/成交价格、基差、持仓量、资金费率、小时历史和深度。
- Gate USDT 线性永续及交割合约使用不同规范身份；不存在的合约和非合约身份不回退到现货。交割合约资金费率显示不支持。
- 管理员可运行明确输入的保证金压力情景，分开显示方向盈亏、手续费和资金费率假设；访客不可提交情景。不是爆仓价计算、历史回测或真实订单。
- 复合提醒提供条件逐项解释、编辑、复制、投递历史；来源过期、缺字段和条件未命中分别显示。
- 研究历史提供日期定位、返回工作区、重试、覆盖与管理员预算受限回补。回补按完整区间去重，最多16个未完成任务。
- 13F 新增披露权重历史、前十集中度、连续披露季度和核验身份的申报日图表入口；历史读取上限24期。季度缺口、修订与未知行业不猜测。
- 公司行动保留来源原始价格与发布时间。仅在原始分区及拆股口径可核验时调整价格；分红或复权口径未知时拒绝计算有争议收益。
- 实验比较保存声明参数、显示配置/费用/样本外差异，关联记录只使用明确实验ID。旧记录显示未关联。
- 行动详情支持前后项与中文状态；Telegram 行动摘要复用状态并附原因、正式网页入口及股票日期定位。

## 边界

来源缺失不造数据；合约只支持本批已明确接入的 Gate USDT 线性产品。未增加币本位、真实下单、强平价、真实交易密钥或TradingView依赖。Telegram实际私聊消息发送不属于本次自动验收。

保留用户已有 `scripts/browser-market-matrix.cjs` 修改、SQLite/数据湖及 `scratch/`；不纳入本批提交。部署只操作 `moneymoney.service`。

## 生产检查修复

首批正式域名四市场只读巡检通过，但新增合约目录实测返回访客403。修复仅开放两个公共GET：`/contracts/catalog`和`/contracts/detail`；情景POST和未知合约路径仍拒绝访客。增加权限回归测试。首页接线增加独立断言，防止模块文件存在但真实首页没有入口。
