# 可信研究与运行体验增强

本轮不改变模拟账户、AI跑单配置或真实交易边界。新增入口留在现有工作区，默认折叠、按需计算；访客不能查询私人记录或撤销操作。

## 如何使用

- 股票或虚拟币图表下展开“策略研究”：手动运行加载耗时诊断、K线自检、环境档案、策略重合、反事实快照或点位布局检查。所有分析均限当前加载区间。
- K线自检中的间隔可由管理员预览并确认回补，复用 `/api/data/backfills`。只支持已接线的美股和 Binance 周期；无日历时标为“待核验间隔”，不能把休市算作缺失。
- 行动中心选择“统一历史 / 安全撤销”：查看已有行动处理、自选元数据及本机图表/布局偏好。撤销前确认版本，冲突时拒绝覆盖；不能撤销订单或修改资金。
- 搜索框使用“实验 AAPL”“订单 AAPL”或“记录 AAPL”：只在当前市场查询最近保存的私人记录摘要。访客不发起私人查询。
- 表格工具中为选定列设置宽度和精度，排序仍使用原数值。不会换算单位、币种或修改源数据。
- 股票财务、期权损益、合约OI/基差、预测结算工作区中分别展开修订、逐腿报价、已归档规则或结算冲突审计。
- 浏览器前进/后退恢复合法工作区上下文；图层和视窗仍使用原有按标的/周期存储。滚动在返回后及下一帧恢复，不承诺未完成异步内容加载后的像素定位。

## 数据与能力边界

| 能力 | 已提供证据 | 不作出的推断 |
|---|---|---|
| 请求诊断 | 当前请求等待、读取解析、来源历史/本次耗时、最近绘制、页面鉴权与下载 | 重叠时间不相加；最大可观测阶段不是因果诊断；REST耗时不是推流延迟 |
| 数据自检 | OHLC、成交量、时间有效性与已加载间隔 | 无交易日历不计算缺失根数；不自动覆盖分区 |
| 策略环境/重合 | 入场前已完成20根、版本化同向重合/冲突/Jaccard | 不从成交量猜流动性，不提供组合边际利润或排名 |
| 反事实 | 已冻结K线、点位和成本假设的Hash与可重放JSON | 收盘情景不是模拟撮合；没有前向轨迹的AI档案只对照原输出/候选信号/不交易，盈亏保持未知 |
| 股票修订 | 相同字段/单位/期间的已发布披露变化 | 不把所有变化都称作重述，不猜测修订原因，不推算未核验13F公司行动 |
| 期权 | 逐腿bid/ask、时间偏差、价差相对中间价成本、乘数 | 不是同步可成交组合价；未计流动性冲击、完整退出及手续费 |
| 合约规则 | 沿既有OI/基差采集保存真实规则字段及同源变化 | 观察日期不是生效日期；旧分区不回填；无生效证据不重算历史费用 |
| 预测审计 | 官方公布/结算冲突、旧新结果、明确时间之间的等待 | 无账户提现证据时资金释放时间未知，不称为无风险收益 |
| 操作历史 | 已记录的处理、自选版本、本机允许范围的偏好 | 不重建旧操作；本机偏好不与资金账户混合；跨标签页冲突拒绝撤销 |
| 演练报告 | 构建阶段临时目录、loopback网络、模型模拟、重复worker和备份/磁盘夹具 | 不是生产故障注入，也不替代线上真实备份恢复记录 |

## 新接口

`GET /api/operations/history?market=stocks` 返回最多200条可安全摘要，管理员、private/no-store。缺少市场时可包含全局自选元数据；不猜测旧元数据的原市场。

`POST /api/operations/history/undo` 只接受已记录的 `action` 或 `metadata`，分别绑定 `expectedUpdatedAt` 或 `revision`。需要现有登录及CSRF；冲突返回409，不接受订单/账户/任意状态。

`GET /api/workspace/records/search?market=stocks&q=AAPL` 只读最近各200条实验/模拟订单，最多20项。返回明确身份和版本，不返回模型输入、预算、报价和账户明细。

现有AI replay响应增加只读 `comparison`；诊断响应增加 `reliabilityDrill`。不存在、非干净提交、不同构建、未来日期或失败演练均不可作为正式通过报告。

## 可复现验收与发布门槛

```powershell
npm run build
npm test
npm run smoke:web
npm run smoke:auth
npm run smoke:browser
npm run smoke:live-kline
npm run smoke:professional
npm run smoke:contracts
npm run smoke:actions
npm run smoke:experience
npm run smoke:practical
npm run smoke:automatic-comparison
npm run security:scan
git diff --check
```

不要在运行全量测试时重新构建：构建会替换 `dist/web/public`，并发读取产物的测试会得到不存在的manifest，不能视为业务回归。性能测量也必须独占浏览器/构建负载。

隔离演练预跑39项通过；修复已实际复现的启动包遗漏、偏好函数重名与页面耗时误归因。浏览器矩阵覆盖三个主题、四市场、窄屏、信号解释、Hash重放与前进/后退；图表推流验收使用隔离传输夹具，不冒充逐笔真实市场验收。

完整测试：313个隔离文件执行成功，Node测试报告1,577项通过、0失败。构建、Web、认证、四市场/三主题浏览器、实时K线、专业研究、合约、行动中心、体验、自动对照、安全扫描及差异检查均通过。新增回补入口不在验收中向生产创建任务。

独占测量：CPU 4倍降速、80ms网络延迟/750kbps，每视口冷/热各3次。1440宽度首屏/图表冷加载中位数1913/2875ms，热加载462/777ms；390宽度冷加载1605/3233ms，热加载490/785ms。热加载脚本传输为0，绝对预算通过；本轮没有配对基线，不声称新增提速百分比。

生产发布结果另行记录；此实现记录本身不表示已发布。发布仅替换dist并重启 `moneymoney.service`，核对运行配置指纹、版本、资源Hash与正式域名，保留旧产物及用户数据。
