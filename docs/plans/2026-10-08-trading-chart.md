# 当前行情交易式 K 线实施计划

用户确认股票、虚拟币现货、合约全部采用截图式体验，保持主题与市场隔离，不使用子 agent，不添加真实下单按钮。

## 设计

采用共用交互装饰器接入现有 Canvas，不引入新运行时、不替换策略/形态/Chan 数据模型。股票与现货默认 5 分钟，显式周期切换继续保留；默认显示最新 60 根，拖拽冻结时间锚点，滚轮调整可见根数，回到最新恢复跟随。顶部 OHLC/涨跌/量/均线与十字光标使用同一可见数据，右侧价签引用最后真实蜡烛；倒计时仅适用于当前尚未结束的短周期，过期显示等待新数据，股票不猜休市时间。

合约沿用 Gate USDT 永续/交割身份，新增同场所 K 线快照入口，默认 5 分钟、15 秒按需刷新，仅采集当前可见合约。报价来源与更新时间明确标为快照/延迟，并不冒充逐笔推流；当前蜡烛保留形成中状态。Gate 无数据时显示真实原因，不回退 Binance 现货。

## 任务与门槛

- [x] `tests/trading-chart.test.cjs`：先失败，覆盖最新窗口、历史锚点、缩放边界、倒计时过期、OHLC；`tests/contract-chart.test.cjs`：严格合约身份、当前 OHLC、错误报价/未来时间过滤、周期与缓存。
- [x] `src/web/public/trading-chart.js`：共享窗口与装饰器、主题控件、价格线/价签/倒计时、十字光标、滚轮/拖拽、回到最新；定时只更新可见图表，不启动其他数据工作区。
- [x] `src/web/public/index.html`：5m 默认、保留原图层与历史 Replay 路径，接入可见窗口和装饰器；不把最新图窗口计算当成全历史回测数据。
- [x] `src/features/contract-research.ts`、`src/web/server.ts`、`src/web/public/contracts-workspace.js`：合约 OHLC API/显示/生命周期，不改订单、预算、AI跑单或现货通道。
- [x] 隔离 Chromium：三市场视图、默认周期、拖拽/缩放/恢复、OHLC、价格和倒计时、市场切换、三个主题、手机和历史路径。
- [ ] 完整测试、构建、Web/认证/浏览器/实时图表、安全扫描、diff 检查，再提交推送；dist 备份部署，仅操作 moneymoney.service，验证正式域名、Hash、健康、已有模拟跑单不变。

## 当前验收证据

- 初始 4 项测试均失败；新增模块及合约入口后通过；另补合约身份错误、来源失败缓存、交割路由及负成交量测试。
- 完整测试：900/900，0 失败；构建：21 个 Hash/预压缩资源。
- Web、认证、四市场浏览器矩阵、合约流程、实时图表及专业研究冒烟通过。
- 截图与推流测试使用明确标记的隔离夹具，不是生产行情证据；生产真实来源检查由 `scripts/verify-trading-chart-release.cjs` 执行。
- 合约字段依据 [Gate 官方 futures API](https://www.gate.com/docs/developers/apiv4/en/futures/)；`v` 是张数，不解释为基础币或 USDT 成交额。不复制第三方业务代码。
- 本批维持股票30秒来源快照、现货 WebSocket/REST降级、合约15秒来源快照。休市、历史/Replay、过期源不会伪装成正在形成的实时蜡烛。
